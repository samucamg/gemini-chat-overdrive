# n8n opcional

n8n não é necessário para os seis conectores locais. Use-o quando um workflow oferecer ações úteis para seu projeto.

Cadastre seu próprio endpoint HTTPS MCP no Gemini e configure autenticação conforme a versão do n8n. Não coloque credenciais em exports de workflows. Os workflows legados deste checkout ficam fora da distribuição 2.0. Crie seus workflows na própria instalação e revise nós, credenciais e schema antes de conectá-los.

[Documentação oficial n8n MCP Server Trigger](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-langchain.mcptrigger/)
