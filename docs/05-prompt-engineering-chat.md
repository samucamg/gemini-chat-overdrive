# Uso e testes de aceite

## Começo da conversa

“Use o notebook Programação com Overdrive e as orientações do projeto. Mostre as ferramentas disponíveis e confirme a pasta antes de alterar arquivos.”

## Diagnóstico local

“Leia o package.json do projeto pelo Filesystem. Execute os testes definidos nele pelo terminal e explique os resultados.”

## Código semântico

“Use Serena para localizar a função indicada, seus chamadores e as referências. Leia o código antes de propor a alteração.”

## Interface

“Liste as abas existentes com Chrome DevTools. Identifique a aba do projeto, confira console e rede e valide o fluxo alterado.”

## Comandos longos

“Execute o servidor de desenvolvimento no terminal. Guarde o identificador do processo e consulte a saída em chamadas posteriores.”

## Aceite por conta

Além de npm run smoke, confirme no Gemini: seleção dos apps, consulta ao Notebook, leitura local, terminal, acompanhamento de processo e leitura de símbolos. O teste técnico do servidor não substitui o teste no cliente Gemini.
